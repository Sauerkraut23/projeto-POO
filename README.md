# projeto-POO
Projeto de um jogo simples que use POO em java.
- Jogo de Batalha Naval Simples
- Usuários podem colocar os navios no tabuleiro, na posição que eles quiserem
- Usuários podem atacar os navios inimigos
- O Programa contará as partidas ganhas de cada um dos players
- O tabuleiro da superfície será de 8x8
- Os navios serão de: 1 casa(3x), 2 casas(2x), 3 casas(2x), 4 casas(1x) e 5 casas(2x)
- Os navios terão os nomes: Corveta(1 casa), Fragata(2 casas), Contratorpedeiro(3 casas), Cruzador(4 casas) e Porta-aviões(5 casas)
